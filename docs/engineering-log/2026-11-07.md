## Decisions and dependencies

- Angular 20, TypeScript strict and Node 24: matches the requested stack; Node 26 on the workstation is outside Angular 20's compatibility matrix. Used npm's isolated Node 24 package to validate.
- ASP.NET Core net10.0, Domain/Application/Infrastructure/API: dependency inversion keeps the Python transport out of the core. The global SDK was 11 preview and lacked ASP.NET Core Runtime 10, so SDK 10.0.100 was installed in ignored `.tools/dotnet`.
- FastAPI 0.121.0, Uvicorn 0.38.0, FastEmbed 0.9.1, Psycopg binary 3.3.8, pypdf 6.2.0. pytest 8.4.2 and httpx 0.28.1 for tests. Full installed dependency snapshot is in `apps/ai-runtime/requirements.lock.txt`; it records the local Python 3.14 resolution, not a validated Linux build.
- Local ONNX multilingual MiniLM embeddings: actual model weights, 384 dimensions, no paid API. Alternative hash vectors were rejected because they do not demonstrate semantics. External APIs were deferred to avoid keys and document egress.
- PostgreSQL/pgvector: relational metadata, transactions and vector search in one database. Dedicated vector services add unnecessary deployment work at this stage.
- Character chunking with overlap: inspectable and configurable; default 350/60, 128 chunks maximum. Token-aware splitting is a next step.
- Versioned migrations plus checksum ledger and advisory transaction lock: support existing database volumes safely. HNSW added at the user's explicit request; approximate recall trade-offs are documented.
- Retrieval context includes source labels, scores, bounded excerpts and explicit insufficient evidence. It does not invoke an LLM or invent references.
- Base64 JSON file ingestion preserves one typed .NET/Python contract; costs about 33% transfer overhead. Multipart streaming remains an alternative for larger files.

See ADR 0001 and ADR 0002 for boundaries and alternatives.
